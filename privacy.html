Privacy Policy

Last updated: October 25, 2026

1. About the Service

DriveTelegramBot2 is a Telegram bot that helps authorized users manage Google Drive file-sharing permissions.

2. Information We Process

The bot processes Telegram user identifiers, Gmail addresses submitted by users, and Google Drive links provided for access requests. Gmail addresses are stored in a local database named users.db.

3. Use of Information

Information is used to process file-sharing requests, identify users, manage access limits, and operate the service.

4. Google API Access

The bot uses Google Drive API permissions granted by an authorized Google account. It only performs operations permitted by the connected account.

5. Storage and Security

Application data is stored on the server hosting the bot. OAuth credentials are used to authenticate authorized API operations.

6. Data Sharing

File-sharing permissions may be granted to Gmail addresses provided for authorized access requests. Relevant information is processed by Google to complete these operations.

7. Data Deletion

Users may request deletion of their stored information by contacting the administrator, subject to applicable requirements.
